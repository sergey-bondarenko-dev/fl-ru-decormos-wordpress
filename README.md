# Decormos WordPress

Кастомный WordPress-проект для контентного сайта Decormos с управляемыми страницами, портфолио проектов и набором собственных Gutenberg-блоков. Проект решает задачу сборки гибкого сайта, где редактор может управлять секциями, проектами, формами и медиа без правки шаблонов.

## Основные возможности

- Кастомная block theme для WordPress с поддержкой шаблонов, меню, логотипа, editor styles и responsive embeds.
- Собственный плагин с Gutenberg-блоками для первого экрана, портфолио, сетки проектов, галерей, FAQ/аккордеонов, секций, карты, статей и форм.
- Отдельный тип записи `project` с категориями, архивом, REST-поддержкой и готовыми паттернами для наполнения проектов.
- Динамический вывод данных через серверные блоки, метаполя, опции темы и источники WordPress.
- Интерактивный frontend: слайдеры, галереи Fancybox, offcanvas-меню, табы, модальные окна, маски ввода и поведение шапки при скролле.
- Интеграция с Contact Form 7 для выбора форм в редакторе и настройки shortcode-атрибутов из блока.
- Локальное окружение на Docker с WordPress, MariaDB и WP-CLI.

## Стек

WordPress 6.8, PHP 8.1+, Gutenberg Blocks, React, JavaScript, SCSS, `@wordpress/scripts`, Carbon Fields, Contact Form 7, Bootstrap 5, Swiper, Fancybox, Docker, MariaDB.

## Особенности реализации

- **Разделение темы и бизнес-блоков.** Тема отвечает за базовые возможности WordPress, настройки и CPT, а Gutenberg-блоки вынесены в отдельный плагин. Это упрощает развитие UI-компонентов и снижает связность проекта.
- **Серверные и статические блоки используются по назначению.** Динамические блоки рендерятся через PHP там, где нужны данные WordPress, формы, метаполя или подборки записей; простые секции сохраняются как разметка Gutenberg.
- **Редактор расширен под реальные сценарии контента.** В проекте есть собственные панели, стили блоков, динамические placeholders, выбор данных из REST-эндпоинтов и настройки для core/image.
- **Frontend-интерактив подключается изолированно.** Общие модули и view scripts блоков инициализируют только нужное поведение: слайдеры, галереи, меню, формы и элементы интерфейса.
- **Проект подготовлен к локальной разработке.** Docker Compose поднимает WordPress и MariaDB, а сборка блоков идет через стандартный инструмент WordPress Scripts.

## Запуск проекта

```bash
cp .env.example .env
docker compose up -d
```

Установить зависимости темы:

```bash
cd themes/decormos-theme
composer install
```

Собрать Gutenberg-блоки:

```bash
cd plugins/decormos-blocks
npm install
npm run build
```

После запуска WordPress будет доступен на `http://localhost:8080` или на порту из `WP_PORT`. В админке нужно активировать тему `decormos-theme` и плагин `Decormos Blocks`.

Проектная WordPress-сборка, сфокусированная на кастомной теме, Gutenberg-архитектуре и управляемом контентном интерфейсе для сайта с портфолио работ.
